# QBCore BurgerShot

A customized BurgerShot job resource for FiveM, built on the QBCore framework.

This project started from an existing public resource and was extensively modified in 2024. Approximately 40–50% of the original resource was customized, with new scripts, updated visual assets, and additional modifications to improve the overall roleplay experience.

## Features

- Customized BurgerShot job functionality
- Additional scripts and modifications
- Updated images and visual assets
- Modified existing resource systems
- QBCore framework integration

## Requirements

- FiveM
- QBCore Framework
- Required dependencies from the original resource

## Installation

1. Download the repository.
2. Place the resource in your FiveM server's resources folder.
3. Configure the resource and its dependencies.
4. Add the resource to your `server.cfg`.
5. Restart your server.
